# ADR 0009: MIT license

- **Status:** accepted
- **Phase:** 0
- **Date:** 2026-09-26

## Context

The library will be published as open source.

## Decision

License the project under MIT.

## Alternatives considered

- Apache 2.0: explicit patent clause (used by Carbon); longer text.
- BSD-3-Clause (used by Lit).

## Consequences

- Permissive and the most common license in the JavaScript ecosystem.

## Traceability

Phase 5 (publication)
