# ADR 0006: Name and brand: Intuition UI

- **Status:** accepted
- **Phase:** 0
- **Date:** 2026-09-26

## Context

The library needs a name available on npm. Candidates were checked against the registry (package, hyphenated variations and scope).

## Decision

Name: **Intuition UI**, published under the `@intuition-ui` scope (`/core`, `/react`, `/vue`, `/svelte`). The brand is communicated as "Intuition".

## Alternatives considered

- `intuition`: package (2014) and scope already registered.
- `intuix`, `intuity`: scope registered.
- `cuia`, `tuiu`, `kuia`: regional identity, less clear.
- `polyui`, `omniui`, `signui`: conflicts with hyphenated versions.
- `agui`: collides with the AG-UI protocol.

## Consequences

- The npm organization `intuition-ui` must still be created to secure the scope.
- GitHub name still to be checked.
