# ADR 0010: Repository language: English

- **Status:** accepted
- **Phase:** 0
- **Date:** 2026-09-26

## Context

The library targets an international audience on npm, while the thesis is written in Portuguese.

## Decision

Code, comments, README, ADRs and the development journal are written in English.

## Alternatives considered

- Code and README in English, ADRs and journal in Portuguese.
- Everything in Portuguese.

## Consequences

- Consistent repository for external contributors.
- ADR and journal content must be translated when writing the thesis.
